#LogGen3000

Vibe coded Login generator as a Telegram-Bot made with Telegram-API on Java.

1. Create the bot and edit the Main.class by puting your Bot-Token (Which you can get both by BotFather bot in telegram)
2. Run the code either on Desktop PC or hosted on Docker compose.
3. enjoy the 30000 combinations of dictionary literate logins in your telegram app <)
